# 黑胶架 · Vinyl Collection Manager

一个零依赖的纯前端单页应用，用来管理你的个人黑胶唱片收藏。数据保存在浏览器本地（localStorage），无需联网、无需后端、无需安装。

## 使用方法

直接用浏览器打开 `vinyl/index.html` 即可。

## 功能

- **收藏库**：网格 / 列表两种视图，封面墙浏览
- **添加 / 编辑唱片**：艺人、专辑、年份、流派、厂牌、规格（LP/EP/Single…）、转速、品相（M/NM/VG+…）、购入日期与价格、五星评分、标签、备注
- **封面**：支持本地上传图片或粘贴图片链接
- **搜索与筛选**：按关键词搜索，按流派、收藏 / 心愿单状态筛选
- **排序**：按添加时间、艺人、专辑、年份、评分、价格排序
- **心愿单**：标记还没入手的目标唱片
- **统计**：藏品数量、总价值、平均评分、按流派 / 年代分布柱状图
- **导入 / 导出**：一键导出 JSON 备份，随时导入恢复或迁移

## 数据安全

所有数据只存在你当前浏览器里。换设备、清缓存前请先用「导出」做备份。

## 技术

原生 HTML / CSS / JavaScript，单文件三件套（`index.html` / `style.css` / `app.js`），无任何第三方依赖。
